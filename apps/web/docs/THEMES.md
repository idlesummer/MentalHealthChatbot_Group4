## 📝 How to Apply a Theme

1. Copy the **Light Mode** section for your chosen theme
2. Replace the `:root` block in `apps/web/src/app/globals.css`
3. Copy the **Dark Mode** section
4. Replace the `.dark` block in `apps/web/src/app/globals.css`
5. Keep the `@theme inline` and `@layer base` sections as-is

## 🎨 Understanding OKLCH Colors

These themes use OKLCH color space for perceptual uniformity:

```
oklch(Lightness Chroma Hue)
```

- **Lightness**: 0-1 (0 = black, 1 = white)
- **Chroma**: 0-0.4 (saturation intensity)
- **Hue**: 0-360 (color angle)
  - Red: ~30
  - Amber/Orange: ~65-70
  - Green: ~140-150
  - Blue: ~240
